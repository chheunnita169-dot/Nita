
# Nita 

A modern web application developed using ReactJS, Vite, and JavaScript. This project is created for learning and practicing frontend web development.

## Technologies

- ReactJS
- Vite
- JavaScript
- HTML5
- CSS
- Git & GitHub


## Requirements

Before starting, install:

- Git
- Node.js
- npm

## Getting Started 

### 1. Clone the repository 
git clone https://github.com/chheunnita169-dot/Nita.git

### 2. Enter the Project Directory

cd Nita

### 3. Install Dependencies

npm install

### 4. Start the Development Server

npm run dev

### 5. Open the Application

http://localhost:5173/


Purpose

This project is created for educational purposes and ReactJS practice.
